# ClairForm

ClairForm lit le règlement d’un appel à projets, en tire la checklist, la compare à vos pièces et signale ce qui manque, ce qui est périmé ou ce qui contredit le règlement.

Ouvrez l’application, puis cliquez sur « Découvrir avec un dossier prérempli ». Chaque visiteur dispose d’un espace privé ; les dossiers sont effacés au redémarrage du Space.
